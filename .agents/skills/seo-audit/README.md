# seo-audit для bergvl.ru

Проектный скилл для доказательного SEO-аудита, а не автоматического исправления сайта. Не требует установки пакетов, скриптов, платных API или дополнительных скиллов.

## Использование в Pi

Каталог `.agents/skills/seo-audit/` обнаруживается как проектный скилл. После добавления выполни `/reload` и проверь доступность команды:

```text
/skill:seo-audit Проверь техническое SEO локальной сборки, без изменения кода.
/skill:seo-audit Проверь страницу vladivostok-khabarovsk.html и её внутренние ссылки.
/skill:seo-audit Сравни локальную сборку и публичные страницы https://bergvl.ru, без публикации.
```

Автоматический выбор определяется полем description в `SKILL.md`. Сам скилл не запускает аудит при загрузке. Сеть и кабинеты необязательны: без них выводы ограничиваются доступными данными. Не передавай агенту пароли и клиентские документы; для анализа трафика используй обезличенные выгрузки.

## Происхождение

Адаптирован из [seo-audit](https://github.com/coreyhaines31/marketingskills/blob/6b9e9387265d9e3049258f7eae3f746d3c3ddf87/skills/seo-audit/SKILL.md) проекта [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills), upstream version **2.2.1**, коммит последнего изменения исходного SKILL.md **6b9e9387265d9e3049258f7eae3f746d3c3ddf87**. Лицензия исходного проекта — MIT, уведомление сохранено в [LICENSE.txt](LICENSE.txt).

Это самостоятельная переработка, а не полная копия upstream. Сохранены порядок аудита и формат доказательных рекомендаций; добавлены:

- Яндекс Вебмастер, Метрика, Wordstat и региональные сигналы;
- Pug/Gulp, источники бизнес-данных, реестр маршрутов и существующие тесты;
- разделение исходников, локальной сборки, production и поисковых данных;
- защита согласованных условий, клиентских данных и служебных страниц;
- запрет автоматических исправлений и публикации;
- оговорки о JSON-LD, длине метатегов, полевых CWV и ограничениях диагностических инструментов.

Ссылки на другие скиллы и инструменты upstream не являются зависимостями адаптации. При обновлении сначала сравни инструкции и лицензию вручную; не заменяй проектные правила скачанным файлом целиком.
