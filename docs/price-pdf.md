# Одностраничный PDF-прайс

## Полная сборка

```sh
npm ci
SITE_URL=https://bergvl.ru npm run build
```

Gulp-задача `pricePdf` создаёт `public/files/price/price.pdf` после остальных
этапов сборки. Это А4, альбомная ориентация, ровно одна страница.
Ссылка скачивания на `pricing.html` ведёт на этот файл.
HTML-макет в `public/` не записывается.

Генерация также выполняется при начальной сборке `npm run dev` и
`gulp validate`. В dev прайс обновляется при изменении шаблонов PDF,
тарифов, общих примечаний, бизнес-данных, используемых шрифтов и логотипа.
После изменения скрипта генератора перезапустите dev-сервер. Ошибка генерации завершает полную сборку с ошибкой:
старый PDF не используется как замена.

Существующие датированные PDF/XLSX в `src/files/price/` остаются без изменений.
Сборка по-прежнему копирует их, но ссылка скачивания прайса на сайте ведёт
на автоматически сформированный PDF. Сборка ничего не публикует на сервер.

## Отдельный просмотр макета

```sh
npm run price:pdf
```

Результат:

- `artifacts/price/price.pdf` — пробный PDF;
- `artifacts/price/price.html` — автономный HTML-макет со встроенными шрифтами и логотипом.

Каталог результата игнорируется Git. Отдельная команда не меняет
`public/`; для обновления сайта запускайте сборку. Закройте PDF в
программе просмотра перед повторной генерацией, если она блокирует файл.

## Устройство

- `gulp/price-pdf.js` — генерация PDF для сборки сайта;
- `scripts/generate-price-pdf.js` — общий генератор и отдельный запуск, рендеринг через Puppeteer,
  проверки размеров и количества страниц через pdf-lib;
- `src/pdf/price.pug` — печатный шаблон без общего интерфейса сайта;
- `src/pdf/price.css` — стили для бумаги;
- `src/pug/tariffs.pug` — тарифы, дата действия и адреса;
- `src/pug/business-data.pug` — контакты и условия хранения;
- `src/pug/pricing-notes.pug` — общие примечания, таблицы подачи машины и
  дополнительных услуг для страницы прайса и PDF.

Цены перевозки и подачи машины не дублируются. В PDF включены девять
тарифицированных направлений, тяжёлый/лёгкий/мелкий груз, подача машины,
негабарит, хранение, дополнительные услуги и контакты четырёх городов.
Состав соответствует `src/pages/pricing.pug`. Полные примечания о лёгком
грузе, негабарите, нормативе погрузки/выгрузки и простое, а также правило
бесплатной подачи машины берутся из общего `src/pug/pricing-notes.pug`.
Надбавка, стоимость простоя и таблица подачи подставляются из `tariffs`.
Две цены допуслуг (уборка, погрузочные работы) заданы один раз в общем
шаблоне. Старый PDF не читается генератором: устаревшие направления и
условия из него не переносятся. Это не полный каталог всех услуг компании.

Для текущей версии Puppeteer нужен Node.js 22.12 или новее.
Puppeteer при установке загружает браузер Chrome for Testing; для установки
нужны сеть и место на диске. Сам рендеринг не использует внешние сервисы:
шрифты PT Sans и логотип берутся из репозитория и встраиваются в HTML.
Для самой генерации PDF не нужны PHP, запущенный сайт и `SITE_URL`.
Для полной сборки `SITE_URL` нужен задаче sitemap.

## Проверка

```sh
SITE_URL=https://bergvl.ru npm run build
node --test tests/price-pdf.test.js
npm run price:pdf
```

Проверяются все тарифные ячейки по исходным данным, контакты, отсутствие
закрытого направления, совпадение полных примечаний сайта и PDF,
подстановка изменённых тарифов в примечания, загрузка шрифтов и логотипа,
отсутствие горизонтального переполнения, высота макета, реальное количество
страниц и формат бумаги. Проверяется также ссылка скачивания на собранный
PDF и отсутствие HTML-макета в публичном каталоге.
При переполнении генерация завершается ошибкой: содержимое не обрезается,
`pageRanges` и автоматическое уменьшение масштаба не используются.
PDF записывается только после успешных проверок.

После правок нужно также открыть PDF и оценить читаемость на А4 при масштабе
100%: программные проверки не заменяют визуальную проверку.
