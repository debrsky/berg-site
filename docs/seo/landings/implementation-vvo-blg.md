# Реализация: Владивосток — Благовещенск

Страница: `src/pages/vladivostok-blagoveshchensk.pug` → `vladivostok-blagoveshchensk.html`.
Реализация выполнена по прямому запросу владельца. По предоставленному владельцем логу `npm run deploy:prod` публикация завершилась успешно: сервер подтвердил развёртывание архива. Независимая проверка production HTTP не выполнялась.

## Дизайн-план и сверка

Основа — `docs/route-landing-design.md` и скилл `frontend-design`.
Сохранены PT Sans, контейнер 1080 px, левое выравнивание, общие компоненты и обе темы.
Токены: фон `#ffffff` / `#171d25`, спокойная подложка `#f2f7fa`, текст `#243746`,
ссылки `#00658c`, маршрутный акцент `#ff8800`; в коде используются существующие CSS-переменные.

```text
Маршрут и действия          Недельный график, сроки
График / Подготовка / Стоимость / Терминалы / Вопросы
Планирование: сдача до 11:00 | заявка до 16:00
Подготовка → четыре примера → терминалы → FAQ → расчёт
```

Вместо типового повторения погрузчика — авторская иллюстрация недельного графика
с двумя независимыми календарными листами: вторник и пятница. У каждого дня своя
машина и короткая стрелка отправления; соединения между днями нет, чтобы их нельзя
было прочитать как начало и конец одного рейса. Это подтверждённый график отправлений,
а не обещание даты выдачи. Общая анимация однократно прорисовывает две отдельные
стрелки и проявляет машины; без JS и при reduced motion рисунок статичен.
На телефоне иллюстрация скрыта, расписание остаётся текстом.

При сверке со старым прототипом выбраны актуальные правила дизайн-документа:
четыре общих примера вместо трёх; названия CTA постоянны; до 16:00 требуется заявка
и на машину, и на сдачу груза на терминал. Якорь «Согласовать отправку» не выдаётся
за телефонный клик или отправленную заявку.

Собственная серия SVG примеров: документы гармошкой, круглая почтовая коробка,
стопка стальных фланцев, экран в защитных торцевых вставках. Это авторская графика,
сторонние изображения не добавлялись. Категории, параметры и расчёт общие.

## Данные и интеграция

- Расписание и сроки — `business.routes`: вторник/пятница, обычно 3 суток,
  гарантия до 5 календарных суток от приёма груза (формулировка уточнена владельцем).
- Контакты — `business.terminals`: отправка Евгений во Владивостоке,
  получение Наталья в Благовещенске. Адреса — `tariffs.terminals`.
- Примеры рассчитывает `calculateCargo`: 350 / 850 / 8500 / 3400 руб.
- Таблицы и дата прайса берутся из `tariffs`, хранение — из `storageTerms()`.
- CTA калькулятора и заявки передают `origin=vvo&destination=blg`.
  Маршрут уже зарегистрирован в `routePages`; используется существующая аналитика.
- Добавлена ссылка с `home.html`; sitemap формируется сборкой.

## Проверки

- `npm run build`, `npm test`, `npm run lint`.
- Отдельные маршрутные тесты: SEO, порядок разделов, расписание, сроки,
  обе отсечки, тарифы, четыре расчёта, SVG, контакты, ссылки и атрибуты аналитики.
- Chromium: 320/360/768/1280 px, обе темы, раскрытые тарифы;
  на 320/360 px текст 200% без горизонтального переполнения страницы.
- При высоте 600 px меню не закреплено, нижняя панель скрыта.
- Якорь согласования переводит фокус к контакту и не прячет его под меню;
  сворачивание тарифов возвращает фокус на summary ниже меню.
- Калькулятор и заявка получают vvo/blg; ошибок консоли лендинга не найдено.
  Навигация к заявке достигла тайм-аута ожидания загрузки, но сама форма открылась,
  и оба города проверены. Внешние интеграции полностью не проверялись.

Заявки и письма не отправлялись. PHP, production HTTP и приём целей Метрикой
не проверялись. Проверки сборки и статической страницы не подтверждают эти интеграции.
