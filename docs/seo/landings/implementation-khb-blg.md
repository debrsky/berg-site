# Хабаровск — Благовещенск

Страница: `khabarovsk-blagoveshchensk.html`, маршрут `khb → blg`.

## Данные
Тарифы и адреса — `tariffs.pug`, контакты и общие условия — `business-data.pug`.
Расписание и сроки для пары не подтверждены: согласование перед отправкой, без заимствования сроков других маршрутов.
Отправка — Татьяна, приём в Хабаровске; получение — Наталья, контакт Благовещенска.
Карта получения — поиск по опубликованному адресу, без выдуманных координат.

## Дизайн-план
Сохраняем токены: белый #ffffff, подложка #f2f7fa, графит #243746,
синий #00658c, груз #0098cc, маркеры #ff8800; тёмная тема — общая.
Шрифт PT Sans, текст слева, цены справа; контейнер 1080px.
Один акцент — груз с маршрутным листом: направление читается как реальная
задача отправки между двумя терминалами, без изображения неподтверждённого пути.
Четыре иллюстрации различаются предметами и силуэтами, а не только гранями
и этикетками: почтовый тубус с документами, плоская коробка с откидной крышкой,
кабельная катушка на транспортных опорах, кресло в защитном чехле.
Общая палитра и контуры сохранены; параметры и расчёт примеров не изменены.
Это условные изображения категорий, а не отдельные тарифы на эти предметы.

```text
[Бренд / Основной сайт]                       [Телефон приёма]
[Хабаровск                 ] [Маршрутный лист + груз]
[Благовещенск              ] [Согласование даты и срока]
[Расчёт] [Заявка]
[Стоимость | Отправка | Терминалы | Вопросы]
[Четыре примера с ценами / подробные тарифы]
[Процесс / время приёма / дополнительные услуги]
[Отправление ○────────────────● Получение]
[FAQ / финальный расчёт и телефон]
```

Проверка плана: новый визуальный язык и декоративные карточки не нужны.
Вместо повторения складской схемы предыдущего лендинга — маршрутный лист
с именами городов и грузом; без географических или временных обещаний.
На телефоне рисунок скрыт, содержание сохраняется; однократная анимация
использует общий route-scene-animation с поддержкой reduced motion.

## Проверка
Сборка перед тестами; отдельные проверки метаданных, цен (250 / 600 /
5750 / 2300 руб.), контактов, ссылок, иконок и регистрации аналитики.
Проверить 320/768/1280px, обе темы, 200% текста, короткое окно и раскрытия.
PHP-отправка заявки не проверяется статическим сервером.

Выполнено: `npm run build`, `npm test` (105 тестов), `npm run lint`,
`git diff --check`. В браузере проверены 320/768/1280px и обе темы,
раскрытые тарифы без горизонтального переполнения. На 320px текст 200%
не раздвигает страницу; при высоте 600px навигация обычная, нижняя кнопка
скрыта. Проверено сворачивание тарифов с возвратом фокуса на summary.
Просмотр через локальный HTTP-сервер, включая полноразмерный снимок светлой
темы и мобильный вид. Отправка письма и внешние карты не проверялись.
