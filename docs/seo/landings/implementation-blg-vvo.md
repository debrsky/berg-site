# Благовещенск — Владивосток: локальная реализация

Страница: `src/pages/blagoveshchensk-vladivostok.pug` → `/blagoveshchensk-vladivostok.html`. Публикация не выполнялась.

## Дизайн и данные

Применены `docs/route-landing-design.md` и скилл `frontend-design`.

- Сохранены PT Sans, контейнер 1080px, общие компоненты, левая ось текста и палитра: `--surface-page` (#ffffff), `--surface-raised` (#f2f7fa), `--text-primary` (#243746), `--text-link` (#00658c), `--brand-color` (#0098cc), `--brand-color-secondary` (#ff8800). Тёмная тема использует существующие токены.
- Композиция: слева города, описание и два действия; справа автопоезд в профиль и простая линия между городами, ниже расписание и сроки. Затем стоимость → подготовка → время приёма → дополнительные услуги → терминалы → вопросы → расчёт.
- Вместо копирования календаря Владивосток — Благовещенск создана отдельная иллюстрация тягача с полуприцепом и подписанными конечными точками. Это условная линия направления, не географическая карта. Общая однократная анимация прорисовывает линию и показывает автопоезд; на телефоне иллюстрация скрыта. Без анимации композиция остаётся полной.
- Четыре оригинальных силуэта: планшет с документами, треугольная транспортная коробка, наковальня на опорах и защищённая стремянка. SVG созданы для проекта, внешние изображения не добавлялись.
- Расписание и сроки берутся из записи `business.routes` для `blg → vvo`: вторник/пятница, обычно 3 суток, гарантированно до 5 календарных суток от приёма груза. Дни отправления не названы днями прибытия.
- Тарифы и адреса — из `tariffs`; примеры рассчитывает общий `calculateCargo`: 250 / 750 / 7 500 / 3 000 руб. при общих параметрах примеров. НДС и исключения указаны рядом с ценами.
- Отправка: Наталья в Благовещенске; получение: диспетчер Яна во Владивостоке. Упаковка до сдачи — требование подготовки, а не предложение услуги в Благовещенске.
- Для CTA зарегистрирован `blg-vvo` в `routePages`. Предзаполнение, защита сохранённых городов, атрибуция и мобильная кнопка используют существующую логику.
- Добавлены входящие ссылки с главной, прайса и страницы Владивосток — Благовещенск. Sitemap автоматически включает self-canonical новой страницы.

## Проверка

- `npm run build` — успешно.
- `npm test` — 135 тестов, все пройдены; добавлены 6 маршрутных проверок, обновлены проверки количества страниц и ссылок.
- `npm run lint`, `git diff --check` — успешно.
- Браузер: 320, 360, 768 и 1280px в светлой/тёмной темах, раскрытые тарифы и FAQ — без горизонтального переполнения. На 320px при корневом размере шрифта 200% переполнения нет.
- При высоте 600px навигация не закрепляется, нижняя кнопка скрыта.
- Клавиатура: Enter раскрывает тарифы и FAQ; нижняя кнопка сворачивания возвращает фокус к summary выше панели навигации.
- Калькулятор и заявка получают `blg → vvo`. В заявке сохранённая пара `khb → vvo` не перезаписывается: показано предупреждение о конфликте.
- Консоль лендинга — без предупреждений и ошибок. Статическое наличие тарифов, контактов, нативных раскрытий и ссылок проверено HTML-тестами; режим браузера с полностью отключённым JavaScript отдельно не проверялся.

Письма не отправлялись, PHP и реальные цели Метрики не проверялись. Публикация требует отдельного разрешения.
