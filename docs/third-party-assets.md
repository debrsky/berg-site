# Сторонние изображения

## Погрузчик на лендинге Владивосток — Хабаровск

- Файл: `src/img/route-forklift.svg`.
- Название: Logistics, стиль Pana.
- Автор / источник: Storyset (Freepik).
- Страница изображения: https://storyset.com/illustration/logistics/pana
- Исходный SVG: https://stories.freepiklabs.com/storage/6264/Logistics-(1)-01.svg
- Условия использования: https://storyset.com/terms (раздел 6).
- Бесплатное использование, в том числе коммерческое, требует указания авторства. На лендинге ссылка на Storyset размещена в футере (`src/pug/landing-layout.pug`); сохраняйте её при использовании иллюстрации без соответствующей платной лицензии.
- Изменения: основной коралловый цвет заменён на фирменный оранжевый `#ff8800`; удалены фоновые коробки, декоративная подложка и растение; область просмотра подрезана под погрузчик с грузом. Детали разделены на группы машины, колёс, вил и груза для анимации.
- SVG включается в лендинг inline. `src/js/common/forklift-animation.js` один раз при появлении иллюстрации запускает въезд с вращением колёс (950 мс), затем подъём вил и груза (750 мс с задержкой 1050 мс). Используется Web Animations API без сторонних библиотек. После проигрывания конечная поза фиксируется атрибутами SVG `transform`, а все анимационные эффекты удаляются, чтобы не сохранять растеризованные анимационные слои. Точка вращения колёс вычисляется по их SVG-геометрии; CSS-центрирование применяется только на время движения. Без JavaScript, без необходимых браузерных API и при `prefers-reduced-motion: reduce` изображение статично; включение уменьшения движения во время анимации останавливает её.

Изображение не распространяется под лицензией кода проекта. Не использовать как логотип, не перепродавать и не включать в коллекции стоковых изображений. Полные условия определяются лицензией Storyset, ссылка выше.
