# Описание проекта bergvl.ru

**bergvl.ru** — сайт транспортной компании «Берг», посвящённый автомобильным грузоперевозкам по Дальнему Востоку. Он помогает клиенту узнать условия и стоимость перевозки, подготовить груз и документы, а также отправить заявку онлайн. В материалах сайта представлены направления между Владивостоком, Уссурийском, Хабаровском, Комсомольском-на-Амуре и Благовещенском.

## Возможности сайта

- **Информация об услугах:** направления перевозок, тарифы, сроки и условия доставки, варианты оплаты, требования к упаковке, контакты подразделений.
- **Расчёт стоимости:** страница `calculator.html` рассчитывает стоимость по направлению и характеристикам груза; актуальные тарифные таблицы также опубликованы на странице прайса.
- **Онлайн-заявка:** форма `order.html` собирает сведения о грузе, отправителе, получателе, погрузке, выгрузке и оплате. Она проверяет поля, предлагает подсказки DaData и позволяет восстановить сохранённые данные формы. Заявка отправляется в PHP-обработчик, который формирует письмо.
- **Документы:** сайт предоставляет договоры, бланки, прайс-листы и другие файлы для скачивания. Отдельная страница `client-doc.html` получает данные счёта через API и формирует счёт или УПД с возможностью печати и сохранения HTML.
- **Контакты с учётом города:** сайт запоминает выбранный город в `localStorage`; если выбор ещё не сделан, пытается определить местоположение через DaData.
- **Дополнительные страницы:** сведения о компании, весогабаритном контроле, политика обработки персональных данных и страница подтверждения отправки заявки.

## Устройство проекта

Это **многостраничный сайт**, а не одностраничное приложение. Исходные страницы находятся в `src/pages/*.pug`, общие элементы — в `src/pug/`. Стили написаны на Less (`src/less/`), клиентская логика — на JavaScript (`src/js/`). Сборка через Gulp компилирует страницы и стили, собирает JavaScript с помощью Rollup и помещает готовый сайт в `public/`.

Серверная часть в `src/php/` решает две основные задачи: отправляет заявки через PHPMailer и предоставляет данные счёта для страницы клиентских документов. Для работы этих функций недостаточно статической раздачи файлов: необходим PHP и соответствующая серверная конфигурация. API счёта также зависит от файлов в серверном каталоге `app/`, которых нет среди исходников сайта.

Основные каталоги:

| Путь | Назначение |
|---|---|
| `src/pages/`, `src/pug/` | Страницы Pug и общие шаблоны |
| `src/less/`, `src/css/` | Стили |
| `src/js/` | Логика форм, калькулятора, контактов и документов |
| `src/php/` | PHP-обработчики заявок и API |
| `src/files/`, `src/img/`, `src/fonts/` | Документы, изображения и шрифты |
| `gulp/`, `gulpfile.js` | Сборка, локальный сервер и публикация |
| `public/` | Результат сборки |
| `tests/` | Автоматические тесты генерации УПД |

## Разработка и публикация

Для установки зависимостей используется `npm install` или `npm ci`. Доступные команды: `npm run dev` — сборка и локальный сервер BrowserSync с отслеживанием изменений; `npm run build` — сборка в `public/`; `npm test` — тесты генерации УПД; `npm run lint` — проверка ESLint.

Публикация предусмотрена в тестовое и производственное окружения командами `npm run deploy:dev` и `npm run deploy:prod`. Настройки адресов и токенов описаны в `.env.template`. Механизм публикации сравнивает файлы сборки с файлами на сервере по хешам и отправляет изменённые файлы архивом. В проекте также есть отдельные Gulp-задачи для FTP и GitHub Pages.

**Внешние интеграции:** DaData для подсказок и определения города, Яндекс Карты на страницах с картами, Яндекс Метрика для аналитики, PHPMailer для отправки заявок. При локальном запуске через BrowserSync можно просматривать собранные страницы, но отправка заявок и получение данных счёта требуют работающего PHP-сервера.
